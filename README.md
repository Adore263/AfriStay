# AfriStay India - Modern Student Accommodation Marketplace

A professional SaaS platform connecting African and international students with landlords in India.

## Project Status
🚀 **Initial Repository Setup** - Ready for comprehensive development

## Features
- Advanced property search and discovery
- Student, Landlord, and Admin dashboards
- Premium membership system (4 tiers)
- AI-powered recommendations
- Real-time messaging
- Community marketplace
- Payment integration (Razorpay)
- Verification system
- Comprehensive analytics

## Tech Stack
- **Frontend:** Next.js 14, React 18, TypeScript, Tailwind CSS
- **Backend:** Node.js, Express, TypeScript
- **Database:** PostgreSQL, Prisma ORM
- **Authentication:** JWT, Role-Based Access Control
- **Real-time:** Socket.io
- **Payments:** Razorpay
- **Maps:** Google Maps API
